Добро пожаловать в репозиторий с моим кодом для игры **The Farmer Was Replaced** 🎮  
Это инди‑игра, в которой основной упор сделан на **автоматизацию фермы с помощью программирования**.

В процессе игры игрок пишет код (на Python‑подобном языке), чтобы управлять дронами, оптимизировать сбор ресурсов и выстраивать эффективные алгоритмы.

## 🗂 Структура проекта

```
TheFarmerWasReplaced/
├── core.py                 # Ядро со всеми вспомогательными функциями
├── main.py                 # Запуск посадки основных видов продукции
├── maze.py                 # Запуск игры "Лабиринт"
├── plant_cactus.py         # Запуск посадки и сортировки кактусов
├── play_companion.py       # Запуск посадки растений в соответствии с их компаньонами
├── play_dino               # Запуск игры "Змейка"
└── README.md               # Описание проекта
```

> ⚠️ Структура может меняться по мере развития проекта.

## 🚧 Статус проекта

🚧 **В разработке**  

На данный момент реализована только часть идей.  
Остальной функционал, оптимизации и новые алгоритмы **находятся в процессе разработки** и будут добавлены позже.
